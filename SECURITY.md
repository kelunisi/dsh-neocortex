# Security Policy

## Reporting a vulnerability

Please report vulnerabilities as a [GitHub Issue](https://github.com/kelunisi/dsh-neocortex/issues). Include a description of the issue, the affected version, and steps to reproduce. We aim to respond within a few days.

## Supported versions

Only the latest 0.4.x release receives security fixes. Older versions are not supported — please upgrade before reporting an issue against an old release.

## Privacy statement

This plugin does not upload any data. Your brain (Markdown files), the local recall ledger, settings, and the weekly-review queue all stay on your machine under your control. Nothing is sent to any remote server by the plugin itself; if you sync your brain folder with third-party sync tools, that is outside the plugin's scope and under your own assessment.
