# 智脑共编规则（通用版）

本页是智脑的"交通规则"：任何接入本智脑的 Agent 都遵守同一套读写约定。本页随模板初始化，可自由修订，修订请追加到 [操作日志](操作日志.md)。

## 地位平等，没有主 Agent

- 任何接入的 Agent 读写权限平等，不存在"主 Agent"；每个 Agent 对自己的写入负责。
- 用户可随时查看 [操作日志](操作日志.md) 核对全部写入历史。
- Agent 不得代用户执行只能由用户本人决定的操作：L1 长期模型确认、周回顾候选的接受/拒绝，只能在 Web 面板由用户操作。

## 三层写入权限

| 层 | 内容 | 写入方式 |
|---|---|---|
| L1 长期模型 | 稳定的个人背景、协作偏好、任务标准 | 写入"待确认区"，**须经用户在面板确认**后才进入已确认区 |
| L2 知识 | 外部知识、可复用资料 | 按规则自动写入 [知识库](知识库/_索引.md)，必须保留来源 |
| L3 近况 | 最近发生的事、进行中的状态 | 可直接写入 [近况](个人模型/近况/索引.md)，受每日配额约束 |

## 读写纪律

1. **先读后写**：写入任何页面前，先读该页面与对应 `_索引.md`；不扫描全库。
2. **原地演进**：在原文位置修改、补充；**不用旧快照整页覆盖**已有内容。
3. **写入留痕**：每次写入后，在 [操作日志](操作日志.md) 追加一条记录（时间、执行者、动作、对象页、理由、会话 ID）。
4. **敏感红线**：不保存密码、凭据或无必要的敏感信息。

## 自然语言控制

用户一句话即可改变当次行为，Agent 必须遵守：

- **"这次不用智脑"** → 本次对话不读、不写。
- **"这个不要记"** → 不沉淀指定内容；已写入的按用户要求处理。
- **"记住这个"** → 写入最合适的页面（L1 进待确认区，L3 直接写近况）。

## 索引先行

- 检索记忆先查各目录的 `_索引.md` / `索引.md`，命中再读正文。
- 各层详情与目录入口见 [从这里开始](从这里开始.md)。
