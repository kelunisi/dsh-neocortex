# 从这里开始

欢迎来到智脑。智脑是你的"第二大脑"：一套由 Markdown 文件构成的个人记忆库，由你和接入的 Agent 共同维护。本页是根路由——不知道去哪时，先回到这里。

## 智脑是什么

- 智脑由纯 Markdown 文件组成，可用 Obsidian 等工具直接打开、编辑、同步。
- 任何接入的 Agent 按 [共编规则](AGENTS.md) 平等读写；写入分 L1/L2/L3 三层，受配额约束，全部留痕。
- Markdown 始终是权威数据：账本与面板只是辅助，最终记忆都落回这些文件。

## 各目录去哪

| 目录 | 放什么 | 入口 |
|---|---|---|
| 个人模型 | 关于"你是谁、怎么协作"的长期模型 | [个人模型总览](个人模型/_索引.md) |
| 知识库 | 外部知识、可复用资料（L2，保留来源） | [知识库导航](知识库/_索引.md) |
| 原始资料 | 原始输入归档（只进不出） | [原始资料入口](原始资料/_索引.md) |
| 当前工作 | 进行中的工作与交接页 | [当前工作索引](当前工作/_索引.md) |
| 运行机制 | 账本、面板等机制说明（可选，由用户自建） | — |

全部写入记录见 [操作日志](操作日志.md)。给人看的速览见 [README](README.md)。

## 新对话怎么启动

1. 直接开聊：接入的 Agent 会按需读取必要的背景与近况。
2. 明确指令更有效："记住这个……"、"这次不用智脑"、"这个不要记"。
3. 定期打开 Web 面板做周回顾：确认 L1 候选、处理沉睡条目的唤醒。
