# 智脑 · 速览卡片

这是一本"新笔记本"的印刷骨架：结构已搭好，内容等你和 Agent 一起填写。完整规则见 [AGENTS.md](AGENTS.md)，路由见 [从这里开始](从这里开始.md)。

## 目录结构

| 路径 | 用途 |
|---|---|
| `AGENTS.md` | 共编规则（所有接入 Agent 必读） |
| `从这里开始.md` | 根路由页 |
| `个人模型/` | 长期模型：背景、偏好、任务标准、近况 |
| `知识库/` | 外部知识（L2） |
| `原始资料/` | 原始输入归档（只进不出） |
| `当前工作/` | 进行中工作与交接页 |
| `操作日志.md` | 全部写入留痕 |

## 三条自然语言控制

- **"这次不用智脑"** → 当次不读、不写。
- **"这个不要记"** → 不沉淀指定内容。
- **"记住这个"** → 写入合适的页面（L1 进待确认区，L3 直接写近况）。

## 隐私提醒

- 不在这里保存**密码、凭据**等敏感信息；如已写入，请删除并在 [操作日志](操作日志.md) 留一条说明。
- 智脑文件只存在你的设备上；是否同步到云端由你使用的同步工具决定，请自行评估风险。
