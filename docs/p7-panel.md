# P7 验收记录：面板 / 悬浮球 / 预算

> 日期：2026-11-09 · 悬浮球与喂养页签

## 后端

| 方法 | 作用 |
|---|---|
| `watchOverview()` | 返回 watch 状态、待确认队列、调度器状态、今日 token 用量 |
| `watchDecide({decision, ids/all})` | 面板/悬浮球里点“收/扔”：收→L2 来源摘要 + L3 近况；扔→只改队列 |
| `updateWatchConfig({scanPerRound, deepPerRound, tokenBudgetPerDay})` | 保存喂养滑块，值按范围钳制 |
| `WatchService.setConfig()` | 原子写 `watch.json`，不改变开关档位 |
| `budget.js` | 每轮估算 token 并记账；调度器在当日预算用尽时记 `budget-stop`、不再跑 |

## 前端

- **悬浮球**：`shell.overlay`，右下角、鲸鱼挂件上方；有待判时显示数字，没有就隐藏；点击展开面板。
- **展开面板**：每行知识点标题 + UP/时长/BV + 要点；[收] [扔]；底部 [全部收] [全部扔] [收起]；操作后数字实时减少。
- **喂养页签**：模式切换、当前待判队列（可逐条收/扔）、三个滑块（扫几条 / 深读几条 / 日 token 预算）、今日预算用量与调度器上次结果。

## 验证

- 全量测试 **103/103**；客户端冒烟 CLIENT-01 确认注册了 `settings.plugins.tab` 与 `shell.overlay`。
- 手动跑了一轮填充队列：新增 5 条待判（显卡降价、黄金行情、DSH 安装、装机显卡、黄金周总结），队列共 10 条（5 已收 + 5 待判）。
- 今日 token 估算用量：`5,168 / 2,000,000`。

## 怎么看到

客户端代码是插件包的一部分，**需要刷新 DSH 窗口（Ctrl+R）或重启一次**才会加载新的 `client.js`。刷新后：

1. 右下角鲸鱼上方出现一个圆球，显示 `5`；
2. 点开能看到 5 条待判，逐条收/扔；
3. 设置 → 插件 → 智脑 → 喂养，也能看到队列和三个滑块。

## 已知边界

- 悬浮球暂未做拖动（固定右下角）；拖动与位置记忆下一步加。
- 行内是 [收][扔] 按钮，不是复选框+提交（功能等价，少一步）。
- 预算用量是估算值（字幕/回复字符折算），不是精确 token 计费。
- “看字幕”链接、历史分页还没做。
