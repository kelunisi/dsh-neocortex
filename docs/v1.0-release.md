## 1. 这一版是什么

v1.0 把 `dsh-neocortex` 从“记忆插件”升级为**读写养成**：

- **读**：R1 回忆（个人模型 + 知识库 + 近况），前 4 轮按问题检索；
- **写**：B 站喂养（搜视频/深读/队列/L2 来源页 + L3 近况）、关注建议、评论回复；
- **自动**：每天 19:00–22:00 随机一轮；评论淘金/草稿/发送自动；关注仍由用户点头；
- **安全**：只读 MCP 白名单、隐私闸、每日额度、412/错误即停、`@owner`；
- **本地**：Markdown + 本地 JSON 账本，不上传云端。
