## 四个真实问题（这轮最大的价值）

1. **第 2 条是高质量样本**：模型给出了可直接复用的"一句领导讲话 + 六条路径 + 标题模板"，置信度 0.90。说明"字幕 + 人设 + 轻量模型"这条路是通的。
2. **第 1 条没有字幕**：`bili_subtitle` 为空，模型只能凭标题判断，置信度 0.40 却仍给了"值得收"。应改为"低置信度 → 待定"，不能当成收。
3. **关键词噪声明显**：`信息报送` 命中了电商涉税，`标准化` 命中了 PLC 工控。这两条与你的工作无关，说明只靠"必含词"不够，需要领域排除词或"方向闸"。
4. **探索位跑偏**：第一版探索位取自首页推荐，结果抓了一条日本美食。正确的探索应该来自"方向词 + 实操/方法/案例"的搜索，而不是首页随机推荐。
