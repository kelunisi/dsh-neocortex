# dsh-neocortex（智脑）

智脑（第二大脑）—— DeepSeek Harness 的 Markdown 权威记忆插件：本地召回账本、生命周期引擎、周回顾与 Web 面板。

## 功能特性

- **分层记忆（L1/L2/L3）**：L1 长期模型（个人背景、协作偏好、任务标准）写入待确认区、经用户确认后转正；L2 知识按规则自动入库且必须保留来源；L3 近况直接写入，受每日配额约束。
- **本地账本与召回解释**：抗崩溃的本地账本记录每次召回与写入，Web 面板可解释"为什么注入这条记忆"。
- **生命周期与周回顾**：场景与条目按有界规则入睡、唤醒、复活、晋升；可断点续跑的周回顾把 L1 候选与沉睡条目排队交给用户处理。
- **Web 面板**：状态查看、召回解释、仅 L1 确认、周回顾操作、L2 只读审计、撤销，以及六个有界参数滑块。
- **空白模板初始化 / 接管**：首次运行可从通用、无个人信息的 Markdown 骨架新建智脑，或接管已有智脑目录且不改动任何已有文件。

## 环境要求

- DeepSeek Harness（DSH）`>= 0.2.1-rc.5`。
- 已在 Windows 上验证。

## 安装

```sh
dsh plugin --profile web add dsh-neocortex
```

或在 DSH 界面的插件市场中安装 `dsh-neocortex`。

## 首次运行

打开 **设置 → 插件 → 智脑 / Neocortex**，运行初始化向导。每种模式都由你自己选择目录：

- **新建智脑**：选择一个空目录，向导会把空白模板复制进去；只要存在同名文件就会中止初始化——不会覆盖任何已有文件。
- **使用已有**：指向已有的智脑目录，向导只做校验，绝不修改已有文件。
- **升级补齐骨架**：指向结构不完整的已有智脑目录，向导只创建缺失的骨架文件，已有文件一律跳过。

## 使用方式

Agent 获得三个工具：

- `neocortex_remember`——按 L1/L2/L3 写入一条原子信息，返回去向、配额或排队结果。
- `neocortex_recall`——检索通用与沉睡个人往事；外部知识问题会路由到网络检索。
- `neocortex_panel`——面板状态、周回顾预览、撤销、执行/重试周回顾、更新有界参数。L1 确认与周回顾候选的接受/拒绝只能由用户在面板操作。

也可以用自然语言控制："这次不用智脑"（不读不写）、"这个不要记"（不保存）、"记住这个"（写入）。

## 卸载

移除插件**不会**删除你的智脑数据：Markdown 文件、本地账本与设置都保留在磁盘上。
